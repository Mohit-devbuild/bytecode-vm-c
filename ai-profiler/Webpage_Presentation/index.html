OVERVIEW

What this project does

The project studies the behavior of a bytecode virtual machine through runtime profiling, with a particular focus on garbage-collector behavior and performance anomalies. The AI-profiler extension uses runtime telemetry to automatically identify unusual executions.

The experimental pipeline combines benchmark workloads, VM profiling metrics, feature scaling, Isolation Forest anomaly detection, visualization, and model evaluation.

RESEARCH

Gaps & contribution

Research gap

Existing work explores machine-learning-based performance anomaly detection, especially in cloud and application settings, but gives less attention to bytecode VMs and language-runtime behavior.

Performance anomalies are also often described through general system metrics instead of VM-specific execution characteristics.

What we did

We apply Isolation Forest directly to bytecode-VM telemetry, combining execution, opcode, garbage-collection, heap, and allocation metrics in one anomaly-detection pipeline.

The detected observations are then examined through visualization and evaluated with precision, recall, F1-score, and a confusion matrix.
